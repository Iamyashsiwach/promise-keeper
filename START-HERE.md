# PromiseKeeper: start here

## What this project does

You ask for a customer spreadsheet in a Switch chat. One agent records what you agreed to; another creates the file. A small program checks that the file matches the agreed columns and row count. You review the checked file. If you change the request, the old approval no longer applies.

## What actually worked

In the first real run, the initial exporter deliberately included unwanted email and internal-note columns. The coordinator caught it, handed the failure to the builder, and verified the builder's correction. The human reviewed the corrected file. Adding email to the requirement created revision 2 and cleared the earlier approval.

The saved history is evidence of a local prototype, not authenticated identity or production-grade security. The first mistake was a planned demonstration using synthetic data.
