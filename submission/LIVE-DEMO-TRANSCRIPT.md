# PromiseKeeper: a team workflow with an approval gate

Three specialist agents handle the customer export while a requester and designated data owner provide independent human sign-off in a Switch room. The room can include the wider team. This 1:36 edited walkthrough uses synthetic orders, real Discord-run footage and AI narration. Cuts remove waiting time; the opening previews the seeded failed check.

## Privacy check catches extra fields.

This exporter finished successfully, but included unwanted columns. PromiseKeeper caught the extra fields and email content. The starting error is deliberately seeded for this demo.

## First, confirm the promise.

In a Switch room, Yash confirms three orders with order number and total only. The coordinator records his actual message before starting work.

## Verified receipt ready for review.

The coordinator hands the failed check to the builder. The builder fixes the exporter, then verifies it once. Receipt one, two passes. Approval is still empty.

## Independent sign-off protects release.

Yash tries to approve his own request. The code refuses. Only the designated data owner can sign off on this checked file.

## Independent review recorded.

Anjali reviews the actual CSV and approves from her own account. The coordinator records her message reference and the verified file hash.

## Approval opens the draft stage.

A third agent checks the code gate before preparing a local message draft. The gate passes for the approved receipt. Nothing is sent to a customer.

## Changed scope resets sign-off.

Yash adds email to the requirements. Recording revision two clears both verification and approval. The old sign off no longer applies, and the email deny policy stays active.

## Fresh review protects the release.

The sender checks again. Release is blocked, and the old draft is marked retracted. PromiseKeeper keeps the request, the checked work, and an independent review connected.
